# トイ・エイト

おもちゃの選手たちが戦う、ブラウザーで遊べる8人制の3Dサッカーゲームです。ブリキ製の「ブリキFC」を操作し、CPUチームと対戦します。

HTML・CSS・JavaScript を `index.html` にまとめた構成で、ビルドやパッケージのインストールは不要です。キーボード、マウス、スマホ・タブレットのタッチ操作に対応しています。

## 起動方法

WebGL に対応したブラウザーで `index.html` を開いてください。Three.js と追加スクリプト、Google Fonts を外部から読み込むため、インターネット接続が必要です。

ローカルサーバーで開く場合は、Python がインストールされた環境で、プロジェクトのフォルダーから次のコマンドを実行します。

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで [http://127.0.0.1:8000](http://127.0.0.1:8000) を開きます。サーバーを停止するには `Ctrl+C` を押してください。

## 遊び方

1. メニューで対戦相手、自分とCPUのフォーメーション、スタジアムを選びます。
2. 「キックオフ」で試合を開始します。
3. パス、ドリブル、シュートを使ってゴールを狙います。守備時は選手を切り替え、タックルでボールを奪います。
4. 試合終了後はスコア、得点者、スタッツ、MVPを確認できます。得点があればハイライトも再生できます。

操作説明・ルールはメニューと一時停止画面から確認できます。対戦相手、自分とCPUのフォーメーション、スタジアム、レーダーの表示設定はブラウザーの `localStorage` に保存されます。

### フォーメーション

いずれもフィールドプレーヤー7人にGK1人を加えた編成です。攻撃時にパスボタンを長押しすると、フォーメーションに応じた特技を狙えます。

| 編成 | 特徴 | 特技 |
| --- | --- | --- |
| 3-3-1 | バランス型。守備を安定させ、中央でつなぐ | ワンツー |
| 2-4-1 | サイド攻撃型。中盤を厚くして両ウイングを活用する | ウイングへのスルーパス。相手側のコーナー付近ではゴール前へのクロス |
| 3-2-2 | 屈強な2トップへの配球型。収めて次につなぐ | 2トップへの浮き球 |

CPUには「おまかせ」も指定でき、試合ごとに編成がランダムで決まります。

## 操作方法

### キーボード

| キー | 攻撃時 | 守備時 |
| --- | --- | --- |
| `WASD` / 矢印キー | 移動 | 移動 |
| `Shift` | ダッシュ | ダッシュ |
| `J` / `Z` | パス。長押しでフォーメーションの特技 | 選手切替。長押しでボール保持者へチャージ |
| `K` / `X` / `Space` | シュート。長押しでパワーをためる | タックル |
| `L` / `C` | — | 選手切替。長押しでボール保持者へチャージ |
| `M` | レーダー（全体マップ）の表示切替 | 同左 |
| `P` / `Esc` | 一時停止・再開 | 同左 |

自チームのGKがボールを保持しているときは、シュート操作がロングキックになります。相手より先に着ける味方の前のスペースへ自動で落とし、ため中は狙う味方（○）と落下地点（◇）が表示されます。長押しするほど遠くの味方を優先します。移動入力で方向を、カーソルで狙う味方を指定できます。狙える味方がいなければ、指定した方向（入力がなければ相手の少ないサイドの前方）へ蹴ります。

### マウス

| 操作 | 動作 |
| --- | --- |
| カーソルを動かす | カーソルの方向へ移動。遠いと自動でダッシュ |
| 左クリック | カーソル先の味方へパス。長押しで特技。守備時は選手切替、長押しでボール保持者へチャージ |
| 右クリック | カーソルの方向へシュート。長押しでパワーをためる。守備時はタックル |

### スマホ・タブレット

- 画面左半分をドラッグして移動します。スティックを大きく引くとダッシュします。
- 画面右下のボタンでパスとシュートを行います。長押しと守備時の動作はキーボードと同じです。
- 画面右上の一時停止ボタンで試合を止められます。

リプレイとゴール後の評価画面は、クリック・タップまたはキー入力でスキップできます。

守備時に切替操作を長押しすると、操作中の選手がボール保持者を追い、近づくと身体を寄せて競り合いでボールを奪います。ゴール前では自分のゴールと相手を結ぶ線上へ入り、シュートコースを塞ぎながらゴール側から詰めます。線上に入るまでは奪取を試みず、横へドリブルされてもゴール側の守備者を優先して選びます。後ろから寄せると奪いにくく、ファウルになることもあります。相手の切り返しにかかると大きく釣られます。ボタンを離すと解除されます。シュートボタンのタックルは強く踏み込むぶん届けば奪いやすい一方、外すと起き上がるまで動けません。

## ルールとテクニック

- **試合時間**：前後半各20分。実時間では各約2分30秒で、演出や一時停止を除くと1試合約5分です。
- **再開と反則**：キックインあり、オフサイドなし。後ろからのタックルはファウルとなり、エリア内ならPKです。ゴール近くの直接FKでは壁越えのカーブシュートを狙えます。
- **勢いとラッシュタイム**：パス、タックル、スキルで勢いがたまり、満タンになるとラッシュタイムに入ります。勢いのたまり方とラッシュの長さは会場によって変わります。
- **ファーストタッチ**：自分へのパスが飛んでいる間にパスを押すと、受ける瞬間に移動入力の方向（入力がなければゴール方向）へボールを押し出します。置く方向は◇で表示されます。`Shift` などでダッシュしていると大きく離れ、近くの相手と逆側へ触れば抜け出せます。予約しなくても、ボールが来た方へ戻る入力でなく、今の向きから大きく向き直る入力なら、ボールを持ったまま前を向きます（マウスはカーソルが3m以上離れているとき）。
- **シュートの適正範囲**：シュートゲージの白い枠の中で離すと、鋭く正確なシュートになります。成功すると効果音・金色の軌跡・振動で知らせます。枠の位置と幅は、ゴールまでの距離、体勢（ダッシュ中・ゴールに背を向けている）、相手の寄せで変わります。ため過ぎると精度が落ちます。
- **クロスの狙い**：2-4-1で敵陣コーナー付近からパスを長押しし、蹴る選手と同じサイドへ方向入力するとニア、逆サイドでファー、入力なしで中央を狙います。マウスはゴール前の狙いたい側へカーソルを置きます。長押し中は着地点の◇と選択名が表示され、離すとクロスを上げます。クロスに入った後は、移動で判定範囲から出てもクロス操作を維持します。
- **クロスへの合わせ**：2-4-1のクロスでは、ボールが頭の高さで通る地点にリングが表示されます。ボールが落ちてくる直前にシュートを押すと、高い球はヘディング、低い球はボレーで合わせます。早く押しすぎると弱くなります。押さなければ受け手がトラップします。
- **2-4-1のサイド攻撃**：両ウイングが幅を保って裏へ走り、中盤とDFが後方の配球を支えます。ウイングがクロスの位置まで運ぶとFWと逆側ウイングがゴール前へ入り、クロス時はさらに中盤も走り込みます。CPUも安全なウイングへの裏パスと、受け手が間に合うクロスを優先します。
- **3-2-2のフィードキープ**：ロングフィードは強めの初速と短い滞空時間でFWへ届きます。受け手になったFWは、落下地点へ自動で先回りし、近くの相手との間に身体を入れてボールを収めます。届く範囲の落下球は競り合いで優先して確保し、受けた直後の0.9秒はチャージで奪われにくくなります。
- **3-2-2のFWへの供給**：DFと中盤はFWへの配球を優先します。受けたFWは通常の保持中もチャージに強く、相方のFWが前方、中盤が後方で落としやこぼれ球を支えます。CPUもロングフィードからFWに預け、寄せられたら中盤へ落として攻撃を続けます。
- **3-3-1のワンツー受け**：最初にパスを出した選手は、予定地点への走り込みから返球の軌道に合わせる移動まで自動で行い、返球中は通常のダッシュより15%速く受けに行きます。加速中は足元に目印が出ます。壁役は長押し中から返球まで、足元のリングと「壁役・背番号・名前」で示します。届く範囲では相手より優先して返球を確保します。受けた後は通常の操作に戻り、ファーストタッチの予約があればその操作を優先します。
- **3-3-1の攻守バランス**：攻撃時はボール側のMFが前方のパスコースへ動き、逆側のMFと中央MFは後方で支えます。中央MFは上がりすぎず、カウンターに備えます。1トップが敵陣でボールを持つとDFもラインを押し上げ、離れた味方はダッシュで追従します。失った後は寄せ・カバー役以外のMFが守備位置へ戻り、大きく遅れていればダッシュで戻ります。
- **味方の連動**：ボールを奪った直後は前線が裏へ走り、失った直後はボール近くの味方が寄せます。ワンツーの壁役は出し手の走り込みを少し待って返し、待っている間にパスを押すとすぐ返します。クロスのときは逆サイドの選手がゴール前へ入ります。
- **切り返し**：ドリブル中に走る方向と逆へ素早く入力すると、近くの相手の逆を取れます。CPUも、長押しチャージで寄せてくる相手を切り返しでかわすことがあります。
- **ルーレット**：ドリブル中に移動入力を一回転させると発動します。キーの順押し、カーソルで円を描く操作、スティックを回す操作に対応し、回転中はタックルを受けません。
- **スタイルポイント**：得点までのプレーに応じてポイントが付き、ゴール後に `B` / `A` / `S` / `SS` のランクが表示されます。

## ファイル構成・実装

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面、スタイル、3D描画、ゲームロジック、CPU、入力処理、効果音 |
| `readme.md` | 起動方法、操作説明、ゲームの概要 |

3D描画には Three.js `0.128.0` を使用し、効果音は Web Audio API で生成します。画質は軽量設定で固定されています。変更する場合は `index.html` 内のチーム定義 `CPU_TEAMS`、会場定義 `STADIUMS`、編成定義 `FORMATIONS` / `FORM_INFO` などを参照してください。
